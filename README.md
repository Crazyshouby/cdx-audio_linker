# cdx-audio_linker (anciennement AudioLinker)

**Audio Linker** — le son du PC sur plusieurs sorties à la fois (enceintes, casques, Bluetooth, HDMI), synchronisées — fait désormais partie de la **suite CDX**,
dont le développement se poursuit dans un dépôt privé depuis le 03/11/2026 (version 1.4.0, sous le nom `cdx-audio_linker`).

- **Versions publiées** (1.0 à 1.3, sous le nom AudioLinker) : dans les [Releases de ce dépôt](../../releases). Elles restent disponibles.
- **À partir de la 1.4** : au premier lancement, les réglages de `%APPDATA%\AudioLinker` sont recopiés dans `%APPDATA%\cdx-audio_linker`, et l'entrée
  « AudioLinker » du démarrage de Windows est remplacée par « cdx-audio_linker ». L'installeur de la 1.4 met à jour une installation d'AudioLinker en gardant les réglages.

Ce dépôt garde l'historique de développement jusqu'à la 1.3.0, la licence ([MIT](LICENSE)) et le [CHANGELOG](CHANGELOG.md) de ces versions.
